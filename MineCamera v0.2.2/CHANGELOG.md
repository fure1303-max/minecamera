# Changelog

## v0.2.2 - 2026-10-15

新增 3:2 4K 极限画质预设，全面重构照片展示框交互体验（空手右键取照片、贴胶卷消耗与旧照片防吞回收、拆除展示框胶卷防丢掉落）。

### Added
- **新增 3:2 4K 极限画质预设**：在预设列表中加入 `3:2 4K`（`3527 x 2351`，829 万像素），支持 3:2 全画幅比例的 4K 极限画质拍摄。
- **展示框空手右键取下照片**：玩家主手空手右键展示框可取下相片，清除展示状态，完整还原并返还包含原拍摄参数与作者信息的已曝光胶卷道具（背包满时掉落于脚边），并播放取下音效。
- **贴上胶卷消耗机制**：生存模式下向展示框贴上相片正常扣减 1 卷已曝光胶卷道具（创造模式不消耗），并播放放入音效。
- **旧相片替换防吞机制**：向已展示相片的展示框贴入新相片时，旧相片会自动转化为胶卷道具返还给玩家背包，杜绝旧照片丢失。
- **展示框破坏防丢掉落保障**：当展示框被破坏且相邻展示框无法继承该相片时，现场自动掉落该相片的已曝光胶卷道具，杜绝相片意外损失。
- **相框元数据持久化**：方块实体通过 `FilmService` 的 `ReadView` / `WriteView` 存储完整 `FilmRecord`，在拼图重组、世界重载时完整保全拍摄元数据。

## v0.2.1 - 2026-10-15

修复手持相机平滑插值抖动与快门卡顿，优化分辨率预设梯队。

### Fixed
- **手持相机移动抽搐卡顿**：修复 `GameRendererMixin.updateCamera` 在手持取景时错误覆盖相机位置与视角的缺陷，手持模式下完整保留原版 60/144+ FPS 的子刻平滑插值（Sub-tick Interpolation），彻底消除行走或转头时的小幅度抽搐。
- **保存完成（已保存）微卡顿**：修复 `MineCameraModeController.onCaptureSucceeded` 在拍摄完成时主线程同步解码 4K 纹理并上传 GPU 的缺陷；取景（LIVE）状态下不再预载大图，仅在玩家主动按 `R` 进入回放（REVIEW）时按需加载。
- **还原 Iris 光影处理**：回滚对 `IrisHandRendererMixin` 的冗余拦截，严格保持与 v0.1.2 一致的光影兼容逻辑。

### Performance & Optimization
- **快门流畅度与预设分级优化**：新增 `1080p` 级标准摄影预设（1:1、4:3、3:2、16:9、21:9）并保留 4K 极限画质预设；标准预设像素量仅为原本 4K 强制拉满的 25%，大幅减轻离屏渲染负载、显存占用与 GPU-CPU 回读时间。

## v0.2.0 - 2026-10-15

核心逻辑审计修复与渲染/存储/网络性能优化。

### Fixed
- **服务端网络线程安全**：在 `MineCameraNetworking` 中将所有 C2S 数据包接收处理调度至 `context.server().execute(...)` 主线程执行，杜绝 Netty 线程跨线程修改玩家背包与方块实体引发的并发异常或刷物品风险。
- **拍照提交超时文件清理**：修复 `MineCameraCaptureCoordinator` 在提交超时或断开连接时未清理本地 PNG 的缺陷，增加自动垃圾回收，防止废弃文件残留占用磁盘。
- **相册索引 JSON 解析健壮性**：重构 `MediaIndexStore`，废弃脆弱的正规表达式文本解析，改用标准 `Gson` 序列化/反序列化，彻底支持字段乱序、玩家名特殊转义字符与多格式解析。

### Performance & Optimization
- **快门异步与防掉帧优化**：将 `ClientCaptureService` 中的高分辨率 PNG 编码、缩略图计算与索引更新移至原版 `Util.getIoWorkerExecutor()` 异步后台线程池，主渲染线程在复制完像素后立即释放 Framebuffer，解决高分辨率保存时的瞬间卡顿冻结。
- **相框未就绪防高频扫盘**：在 `ClientPhotoTextureCache` 增加未就绪/缺失媒体的短期冷却缓存（3 秒），避免展示框在等待网络同步期间每帧高频扫描磁盘。
- **消除高频交互反射**：创建 `CameraClientHooks` 解耦界面调用，彻底消除玩家右键相机和三脚架时的 `Class.forName` 反射性能损耗。


完成照片展示框 V1，并重构相机实时取景链路。

### Added
- 展示框支持单框照片显示、多框矩形自动拼图、放置/拆除后的重新分组和局域网缩略图同步

- 展示框照片保持宽高比并裁切铺满，拼接内部边框隐藏，单框边框缩窄至每边保留 `1/16` 格
- 照片缺失时显示明确的缺失照片占位图，空展示框保持原模型显示

- 三脚架实时取景读取玩家当前视角，回放读取已保存机位，避免转动视角回弹卡顿
- 21:9 分辨率预设同时限制总像素和单边尺寸，避免超出渲染上限导致 `invalid_capture`

### Tests
