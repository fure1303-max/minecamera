# Changelog

## v0.1.2 - 2026-07-30

完成照片展示框 V1，并重构相机实时取景链路。

### Added
- 展示框支持单框照片显示、多框矩形自动拼图、放置/拆除后的重新分组和局域网缩略图同步
- 不规则展示框区域按最大面积拆分为多个矩形，局部点击只影响所在矩形
- 展示框照片保持宽高比并裁切铺满，拼接内部边框隐藏，单框边框缩窄至每边保留 `1/16` 格
- 照片缺失时显示明确的缺失照片占位图，空展示框保持原模型显示

### Changed
- 实时取景改为主世界单次渲染，取景框外使用纯黑遮罩，删除持续离屏预览和预览纹理刷新链路
- 手持相机和三脚架共用相机位置、朝向、焦距与照片比例构图；回放时保持拍摄机位
- 相机模式隐藏第一人称手部及相机物品，并保留高分辨率离屏 PNG 拍照链路与 Iris 兼容
- 三脚架实时取景读取玩家当前视角，回放读取已保存机位，避免转动视角回弹卡顿
- 21:9 分辨率预设同时限制总像素和单边尺寸，避免超出渲染上限导致 `invalid_capture`

### Tests
- 增加展示框分组、纹理 UV、网络同步、缓存、NBT 和渲染几何相关测试
- 增加相机生命周期、三脚架视角、照片比例 FOV 换算和 21:9 分辨率回归测试
