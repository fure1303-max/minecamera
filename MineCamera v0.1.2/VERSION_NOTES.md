# MineCamera v0.1.2 版本开发与功能记录

## 1. 版本基本信息

- **版本号**：`v0.1.2`
- **对应构建产物**：`release/minecamera-0.1.2.jar`
- **支持环境**：`Minecraft Java 1.21.11` + `Fabric Loader 0.19.3` + `Java 21`
- **来源与定位**：本项目初始从 GitHub 官方仓库（`fure1303-max/minecamera`）拉取导入的稳定基准版本。

---

## 2. 该版本已实现的核心功能与特性

### 2.1 相机取景与控制
- **手持相机取景器**：手持相机右键开启 HUD 取景器界面，画面带有中心十字线与构图辅助框，主界面遮罩周围视角。
- **实时光学焦距调节**：支持通过鼠标滚轮在 `10mm` ~ `600mm` 范围内无级调节焦距，配合 `Shift` 键可实现快速大跨度变焦。
- **分辨率与比例预设**：支持按 `Tab` 键在不同画面比例间轮换（1:1、4:3、3:2、16:9、21:9），当前版本均以 `maxPreset` 计算（上限约 829 万像素，即 4K 级别）。

### 2.2 三脚架系统
- **三脚架方块**：放置后可手持相机 `Shift + 右键` 安装相机，空手 `Shift + 右键` 拆卸相机。
- **独立机位拍摄**：对已安装相机的三脚架右键即可进入三脚架视角，机位固定在三脚架上方中心位置，角度可由玩家在取景时调整。

### 2.3 胶卷机制与本地保存
- **胶卷生命周期**：玩家背包内持有“空白胶卷”时方可按下左键拍照；拍摄成功后消耗 1 个空白胶卷并生成 1 个“已曝光胶卷”。
- **离屏渲染与保存**：拍照时创建专用离屏 Framebuffer 并二次调用 `renderWorld`，生成的画面以 `<mediaId>.png` 保存于客户端 `<runDirectory>/minecamera/captures/` 目录。
- **HUD 相册回放**：在相机界面中按 `R` 键切换至回放模式，通过 `A` / `D` 键前后翻阅背包中的已曝光胶卷。

### 2.4 照片展示框
- **单框与自动拼接**：手持已曝光胶卷右键展示框可展示照片；相邻的同朝向展示框会自动按照空间连续性与贪心算法组合为矩形大画幅，隐藏内部相连边框。
- **宽高比裁切与保真**：矩形展示框根据照片原始宽高比自动进行居中裁切铺满。
- **局域网缩略图网络同步**：多玩家局域网联机时，仅按需向其他客户端同步轻量化展示缩略图，不跨网络传输原始大图 PNG。

### 2.5 基础光影与着色器兼容
- **Iris / Sodium 兼容**：集成了 `IrisHandRendererMixin`，在离屏捕获时抑制第一人称手部渲染，防止手部遮挡画面。

## 3. 该版本存在的已知问题与缺陷（待在后续版本修复）

1. **快门卡顿严重**：拍摄时主线程同步执行 PNG 压缩写入与缩略图计算，拍摄瞬间会产生长达 1~2 秒的画面假死。
2. **异常断连文件残留**：网络超时或断开连接时，未提交到服务端的废弃本地 PNG 文件未能自动删除。
3. **JSON 解析脆弱**：`MediaIndexStore` 使用正则表达式匹配 JSON 字段，在遇到玩家名含有特殊字符、转义符号或字段顺序变动时容易读取失败。
4. **网络线程安全隐患**：服务端 C2S 数据包接收在 Netty 网络线程中直接修改玩家背包物品与方块实体，存在并发与刷物品风险。
5. **反射开销**：相机与三脚架交互中使用了 `Class.forName` 方式反射调用客户端界面。
6. **相册缓存高频扫盘**：展示框未下载完成缩略图时，每帧都会向本地磁盘发起读取探测。
