## MineCamera v0.2.0

### 核心变更与优化
本版本主要针对模组核心逻辑进行全方位安全性审计、性能异步化重构以及工程化规范升级。

### 修复 (Fixed)
- **服务端网络线程安全性修复**：将所有 C2S 数据包（拍摄提交、缩略图请求等）的处理强制调度到 Minecraft 游戏主线程（`context.server().execute`）执行，彻底解决 Netty I/O 线程并发修改玩家背包与方块实体可能导致的崩溃与刷物品漏洞。
- **拍照提交超时未提交废弃文件清理**：引入会话超时管理机制（15 秒超时判定及断连监听），若拍照提交失败或断开连接，自动清理客户端本地残留的无用 PNG 文件，防止垃圾堆积。
- **相册索引 JSON 解析重构**：全面使用 Google Gson 进行标准化类型安全序列化与反序列化，废弃原本脆弱的正则表达式匹配，稳定支持特殊转义字符、玩家名乱序与多语言字符。

### 性能优化 (Performance & Optimization)
- **快门异步写盘与防假死**：将高分辨率 PNG 压缩写入、缩略图计算与索引写入移至后台线程池（`Util.getIoWorkerExecutor`）异步执行，拍照瞬间主渲染线程不再出现 1~2 秒的画面假死。
- **相框未就绪缓存冷却保护**：为未下载完成或缺失的展示框照片增加 3 秒读取冷却缓存，杜绝每帧持续高频扫描本地磁盘的性能损耗。
- **消除高频交互反射**：重构客户端接口钩子（`CameraClientHooks`），删除了相机与三脚架交互时的 `Class.forName` 反射调用。

### 运行环境要求
- Minecraft: `1.21.11`
- Fabric Loader: `0.19.3`
- Fabric API: `0.141.4+1.21.11`
- Java: `21`
